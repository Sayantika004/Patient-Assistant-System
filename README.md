# Patient Assistant System

An AI-powered patient assistance workflow built using UiPath Studio Web, AI Agents, and Maestro BPMN.

## Overview
The Patient Assistant System helps process patient queries, analyze symptom severity, and route cases through a doctor approval workflow.

## Key Features
- **Query Assistant Agent:** Assists with processing patient queries.
- **Severity Analysis Agent:** Analyzes reported symptoms and severity.
- **Doctor Approval App:** Supports doctor review and approval or rejection.
- **Email Generation Agent:** Generates email content based on the workflow.
- **SendEmail Workflow:** Handles email communication.
- **Maestro BPMN:** Coordinates the overall workflow.

## Technologies Used
- UiPath Studio Web
- UiPath AI Agents
- UiPath Maestro BPMN
- UiPath Apps
- GitHub

## Workflow
1. A patient query enters the workflow.
2. The query is processed by the Query Assistant Agent.
3. The Severity Analysis Agent analyzes the reported symptoms.
4. The Doctor Approval App supports the approval or rejection process.
5. If approved, the workflow generates and sends an email.
